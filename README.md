# Clima Agora

Aplicação web em JavaScript, CSS e Bootstrap para consultar previsão do tempo de forma rápida e agradável.

## Recursos

- Busca por cidade ou região.
- Uso da localização atual do navegador.
- Exibição das condições atuais com temperatura, sensação térmica, vento, umidade e precipitação.
- Previsão resumida para os próximos 5 dias.
- Interface responsiva com visual moderno.

## Como executar

Basta abrir o arquivo `index.html` em um navegador moderno com acesso à internet.

## APIs utilizadas

- Geocoding API da Open-Meteo.
- Forecast API da Open-Meteo.
